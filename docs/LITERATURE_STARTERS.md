# Verified literature review (research stage)

This is a source-backed initial review, not a claim that all relevant literature has been exhausted. Publication metadata and claims below were checked against publisher, proceedings, or author/institution pages on 2026-11-13. Results from other languages and professions motivate methods but are not evidence of expected performance on Turkish backend resumes.

## Synthesis

The literature supports a controlled comparison and human judgments at the *job-specific ranking* level, while showing that results depend on domain, text selection, labels, and representation. No cited result validates a Turkish backend ranking model. A Turkish job-ad skill dataset may support a later skills-extraction component if access permits, but it cannot substitute for resumes or relevance labels. Thus the key research gap is not merely model choice: it is an authorized Turkish CV source and a reproducible set of multiple CVs judged against each posting.
